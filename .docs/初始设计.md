# 猫猫报纸初始设计

2026-10-26：用户确认 RSS/Atom 方案并授权自动开发直至本机 Docker 部署。

- 每日配置时区的固定时间收集前一自然日的公开新闻。
- 可配置主题与每类上限，不足上限时不补历史新闻。
- 原文标题、正文、时间和链接保存为独立 Markdown，不翻译或摘要。
- 挂载大存储盘 bind mount 保存文档、状态和日志；每轮清理临时产物。
- 去重后通过受保护的外部 AstrBot 接口导入现有知识库。
- 2026-11-01 修订：生产部署迁至 macmini，本机只开发与构建；无 LLM、新闻 API 或 MCP 运行依赖。
- 所有个人主题、来源列表与凭据位于被忽略的 .env/；参考原件位于 .ref/。

详细实现和状态以开发计划-SSOT.md 为准。
